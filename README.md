Sistema web para la gestión de clientes y proyectos

Activa CRM es un proyecto académico orientado al diseño de un sistema web que centraliza la información de clientes, proyectos, tareas y su seguimiento.

Objetivo
Diseñar un prototipo que facilite la consulta y administración de clientes, la asignación de responsables y el seguimiento del avance de los proyectos.

Tecnologías previstas

- HTML
- CSS
- JavaScript
- Python
- Flask
- SQLite
- Git y GitHub para el control de versiones

Estructura del repositorio

- `documentacion/`: requerimientos, diagramas y documentos del proyecto.
- `prototipo/`: interfaces gráficas y archivos del prototipo.
- `evidencias/`: capturas de pantalla y avances.
- `README.md`: descripción general del proyecto.

Alcance inicial

El MVP contempla autenticación, gestión de clientes, proyectos, tareas, permisos básicos y almacenamiento en SQLite. Las integraciones externas y las funciones avanzadas de inteligencia artificial se consideran posibles ampliaciones futuras.

Estado del proyecto

En desarrollo: documentación, diseño de interfaces y preparación del prototipo.

Control de versiones

El desarrollo se documentará mediante commits que registren el inicio, los requerimientos, las actualizaciones, la integración del prototipo y la versión final.
